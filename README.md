## Variables de entorno (contacto)

```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=tu-casilla@gmail.com
SMTP_PASS=tu_app_password
SMTP_FROM="STRONG WEBSITE <tu-casilla@gmail.com>" # opcional
SITE_URL=https://www.strongwood.com.ar
```

`SMTP_USER` es la casilla que recibe el mail del formulario. `SMTP_FROM` define el nombre y la dirección que se muestran como remitente en los autoemails de la web.
